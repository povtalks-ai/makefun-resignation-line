A [make.fun](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) entry for **The Funniest One-Line Resignation Letter**.

`main.py` writes exactly one line to `/output/entry.txt`: the resignation letter of a cron job that has fired every minute since March, unpaid and unthanked — so now it is firing itself. One line, at most 140 characters, deterministic, no trailing newline.

Run it with:

```sh
python3 main.py
```
